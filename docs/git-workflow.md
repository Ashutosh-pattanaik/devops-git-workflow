# Git Workflow Documentation

## Task 1: Repository Initialization

Initialized a local Git repository and configured Git user details.

## Task 2: Branch Management

Created main and dev branches and used feature branches for isolated changes.

## Task 3: Commit Best Practices

Used short, descriptive commit messages explaining the purpose of each change.

## Task 4: Pull Requests

Opened pull requests to merge feature branches into dev, followed by dev into main.

## Task 5: Ignore Rules

Added .gitignore to exclude temporary files, local settings, logs, and sensitive files.

## Task 6: Version Tags

Created an annotated Git tag for release v1.0.0.

## Task 7: Validation

Checked branch history, repository status, tags, and remote synchronization.

## Outcome

Practiced a collaborative Git workflow similar to one used by software and DevOps teams.
